# Copilot Stats Privacy Policy

**Privacy Policy**

Privacy Policy for Copilot Stats macOS Application

Effective Date: February 28, 2026

Thank you for choosing Copilot Stats! This Privacy Policy explains how we collect, use, and disclose information in relation to our macOS application available on the Mac App Store. Please read this policy carefully to understand our practices regarding your privacy and how we handle your data.

1. Information Collection

    Copilot Stats is designed to respect your privacy, and as such, it does not collect any personal information or user data from your device. Our application does not require any registration or sign-in process beyond providing your GitHub Personal Access Token for API authentication. We do not collect, store, or transmit any personally identifiable information (PII), including but not limited to names, email addresses, or contact information.

2. KeyChain Integration

    Copilot Stats utilizes the KeyChain feature provided by macOS to securely store your GitHub Personal Access Token. The KeyChain is a native macOS service that stores sensitive data locally on your device, ensuring its privacy and security. Your API token is stored within the KeyChain, encrypted and protected using industry-standard security measures. This token never leaves your device and is only used to authenticate API requests to GitHub.

3. Use of Information

    Since we do not collect any user data, we do not use the information for any purpose. The Copilot Stats application is solely designed to provide you with its intended functionality - displaying your GitHub Copilot usage statistics - without compromising your privacy. We do not analyze, sell, or share any user information with third parties. All data processing occurs locally on your device.

4. Third-Party Services

    Copilot Stats integrates with GitHub's official API to retrieve your Copilot usage statistics. When you use the application, it makes authenticated requests directly from your device to GitHub's servers using your Personal Access Token. The data retrieved includes:
    
    - Your GitHub username
    - Copilot premium request usage statistics
    - AI model usage breakdown
    - Billing period information
    
    These requests are made directly between your device and GitHub's servers. We do not intercept, store, or transmit this data to any other parties. Please review GitHub's privacy policy at https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement to understand how GitHub handles your data.

5. Data Security

    We take the security of your information seriously. By utilizing the KeyChain feature provided by macOS and the App Sandbox security model, we ensure that your GitHub Personal Access Token is stored securely on your device. We continuously strive to implement industry-standard security measures to protect your data from unauthorized access, alteration, disclosure, or destruction. The application operates within macOS's secure sandbox environment, limiting its access to only the network resources necessary to communicate with GitHub's API.

6. Data Storage and Retention

    All data displayed in Copilot Stats is:
    
    - Fetched directly from GitHub's API in real-time
    - Temporarily cached in memory during app operation
    - Not persisted to disk beyond system-level caching
    - Automatically cleared when the application is closed
    
    Your GitHub Personal Access Token is the only data stored persistently, and it is stored securely in the macOS KeyChain. You can delete your token at any time through the application's Settings window.

7. User Rights and Control

    You have complete control over your data:
    
    - You can delete your stored GitHub Personal Access Token at any time through Settings
    - You can revoke the token directly in your GitHub account settings
    - You can uninstall the application at any time, which will remove all associated data
    - No data is retained after uninstallation

8. Children's Privacy

    Copilot Stats is not directed to children under the age of 13. We do not knowingly collect personal information from children under 13. If you are a parent or guardian and believe your child has provided us with personal information, please contact us.

9. Changes to Privacy Policy

    We reserve the right to modify or update this Privacy Policy from time to time. Any changes we make will be effective immediately upon posting the updated policy to https://menubar-apps.github.io/privacy/copilot-stats.html. We encourage you to review this Privacy Policy periodically to stay informed about our privacy practices. The "Effective Date" at the top of this policy indicates when it was last updated.
